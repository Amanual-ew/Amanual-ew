A web-based platform connecting car owners with people looking to rent vehicles in Addis Ababa.

**Key Features**
- Car listings and management.
- Booking management.
- User authentication.
- Rental administration.

**Technologies:** Next.js, TypeScript, Prisma, PostgreSQL.
